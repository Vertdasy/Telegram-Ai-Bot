# Telegram-бот с ИИ

[English version](README.md) · Демо: [@aibottext_bot](https://t.me/aibottext_bot)

Многофункциональный Telegram-бот на любой **OpenAI-совместимой нейросети** (DeepSeek, OpenAI, OpenRouter и др.).
Python, **aiogram 3**, **SQLite**. Полностью локализован (🇷🇺 / 🇬🇧), включая админ-панель, а настраивается
целиком из самого Telegram.

## Возможности

**Для пользователей**
- 💬 Ответы потоком, Markdown → HTML Telegram, автоматическая разбивка длинных сообщений
- 🖼 Фото (до 6, альбомы) и 📎 документы: txt, код, docx, pdf, xlsx, pptx
- 🔎 Поиск в интернете (Tavily / Brave / запасной без ключа) — модель вызывает его сама
- 🎭 Режимы: Обычный, Переводчик, Программист, Редактор + свои инструкции (`/myprompt`)
- 🧠 Память диалога, 📌 сохранённые сообщения, кнопки «Повторить / Продолжить», ⏹ «Стоп», очередь запросов
- 📤 `/export` диалога файлом, 🎁 реферальные бонусы, 🌐 выбор языка

**Для администраторов** (`/admin`, с локализацией)
- 📊 Статистика, список и карточки пользователей, бан/разбан, рассылка, журнал ошибок, бэкап БД
- 🧠 Выбор модели, запасная модель, уровни скорости («быстро» / «вдумчиво»), тест скорости
- 📝 Редактор промптов по режимам, 🧮 память, ⏱ лимиты, 🔎 веб-поиск, 🎁 настройки приглашений
- 🔗 Учёт источников трафика по ссылкам `https://t.me/<бот>?start=<метка>`, 🔧 режим обслуживания

## Быстрый старт

Нужен Python 3.10+.

1. Создайте бота в [@BotFather](https://t.me/BotFather), скопируйте токен.
2. Узнайте свой Telegram ID в [@Getmyid_bot](https://t.me/Getmyid_bot) — это нужно сделать, чтобы вписать в переменную админов.
3. Получите API-ключ у любого OpenAI-совместимого сервиса (запишите адрес API и название модели).
4. Настройте:
   ```bash
   cp .env.example .env
   ```
   Заполните `TELEGRAM_TOKEN`, `AI_API_KEY` и `ADMIN_IDS`. Проверьте, что `AI_BASE_URL`, `ID_MODEL` и `VISION_MODEL`
   соответствуют провайдеру, для которого вы получили API-ключ. В примере указан текущий адрес API по умолчанию;
   замените его, если используете OpenAI, OpenRouter или другой совместимый сервис. Не добавляйте настоящий файл `.env`
   и API-ключи в Git.
5. Запустите:
   ```bash
   pip install -r requirements.txt
   python main.py
   ```
6. Откройте бота в Telegram, отправьте `/admin` и настройте всё оттуда.

### Хостинг

Подходит любой хостинг с Python (Amvera, Railway, Render, VPS и т. д.). Загрузите весь проект, команда запуска —
`python main.py`; загрузите `.env` или задайте те же переменные в панели хостинга (они приоритетнее файла).
База должна лежать на постоянном диске: по умолчанию `/data/bot.db`, если есть папка `/data`, иначе `./bot.db`
(можно задать через `DB_PATH`).

## Настройки

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_TOKEN` | — | **Обязательно.** Токен бота |
| `AI_API_KEY` | — | **Обязательно.** Ключ нейросети |
| `ADMIN_IDS` | — | Telegram ID админов через запятую |
| `AI_BASE_URL` | `https://ai.starimg.ru/v1` | OpenAI-совместимый адрес API |
| `ID_MODEL` / `VISION_MODEL` / `FALLBACK_MODEL` | модели DeepSeek | Основная, для фото и запасная модели |
| `MODELS` | 3 модели DeepSeek | Модели, доступные в админке |
| `TAVILY_API_KEY` / `BRAVE_API_KEY` | — | Необязательные бэкенды веб-поиска |
| `WEB_SEARCH` | `1` | Поиск включён по умолчанию (0 — выкл.) |
| `MEMORY_LEN` | `30` | Сообщений в памяти на пользователя |
| `RATE_PER_MIN` / `RATE_PER_DAY` | `5` / `100` | Лимиты по умолчанию |
| `MAX_FILE_MB`, `MAX_DOC_CHARS`, `MAX_DOCS` | `10`, `30000`, `5` | Ограничения документов |
| `REF_BONUS` / `REF_MAX` | `20` / `25` | Бонус за друга и максимум друзей |
| `TZ_HOURS` | `4` | Сдвиг от UTC для времени в админке |
| `DB_PATH` | см. выше | Путь к файлу SQLite |

Остальные параметры (таймауты, очередь, частота обновления стрима и др.) описаны в `aibot/config.py`.

## Локализация

Все тексты — в JSON-файлах `aibot/locales/<язык>/`:

- `user.json` — тексты для пользователей и команды бота (ключи `cmd_*`)
- `admin.json` — тексты админ-панели (ключи `adm_*`)
- `modes.json` — базовый промпт и режимы (название, описание, промпт)

Значение — строка или список строк. Подстановки: `{name}`.

**Добавить язык:** скопируйте `locales/en` в `locales/<код>`, переведите значения и задайте `lang_name`
(например, `"🇩🇪 Deutsch"`) в `user.json`. Язык появится в выборе автоматически. Команда
`python -m unittest discover tests` проверит, что во всех языках одинаковые ключи и подстановки.
Админ-панель использует язык самого админа; кнопка 🌐 в панели переключает его.

## Приватность и данные

Бот хранит историю диалогов, сохранённые сообщения, пользовательские настройки и технические записи в базе SQLite.

Когда пользователь отправляет запрос, бот передаёт соответствующий текст и нужный контекст диалога провайдеру ИИ,
указанному в `AI_BASE_URL`. Если используется веб-поиск, поисковый запрос передаётся выбранному поисковому сервису.

Команда `/export` позволяет скачать историю диалога и сохранённые сообщения. Команда `/clear` очищает историю
после подтверждения и предлагает при необходимости удалить сохранённые сообщения. Очистка диалога не удаляет
технические записи о запросах, поиске и ошибках или настройки пользователя из базы данных.

Оператор бота отвечает за защиту сервера и базы данных, настройку срока хранения данных и проверку политик
конфиденциальности подключённых сервисов. Не отправляйте чувствительные данные, если не согласны с условиями этих провайдеров.
