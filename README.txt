TELEGRAM-БОТ С ИИ — ИНСТРУКЦИЯ ПО ЗАПУСКУ
==========================================
Программировать не нужно. Время: 15–20 минут.
Бот работает на любом хостинге, где можно запустить приложение на Python 3.10 или новее.

ЧТО В АРХИВЕ
  main.py           — сам бот
  requirements.txt  — список нужных библиотек (хостинг ставит их сам)
  .env.example      — шаблон настроек
  README.txt        — эта инструкция

 https://t.me/aibottext_bot - рабочий бот

настройка бота происходит в боте через /admin


ЧАСТЬ 1. ПОДГОТОВКА (одинаково для любого хостинга)

1) Создайте бота в Telegram
   - Найдите в Telegram @BotFather, нажмите «Запустить».
   - Отправьте команду /newbot, придумайте название и имя (имя должно заканчиваться на bot).
   - BotFather пришлёт ТОКЕН — длинная строка вида 123456:ABC-DEF... Сохраните её.

2) Узнайте свой Telegram ID
   - Напишите боту @Getmyid_bot. Он ответит числом (Id). Это нужно, чтобы вы могли
     открывать админ-панель бота.

3) Получите ключ нейросети
   - Подойдёт любой сервис, совместимый с OpenAI: OpenAI, DeepSeek, OpenRouter и подобные.
   - Зарегистрируйтесь, пополните баланс, создайте «API key» и сохраните его.
   - Запишите ещё две вещи: адрес API (например, https://api.openai.com/v1)
     и название модели (например, gpt-4o-mini). Их подскажет раздел документации сервиса.


ЧАСТЬ 2. НАСТРОЙКИ БОТА

Бот читает настройки двумя способами. Достаточно ОДНОГО из них.

СПОСОБ А. Через файл .env (подходит для любого хостинга)
   1. Скопируйте файл .env.example и назовите копию .env (точка в начале, без .txt).
      Если система прячет файлы с точкой — откройте .env.example в Блокноте и сохраните
      как .env (тип файла «Все файлы»).
   2. Откройте .env в Блокноте и впишите значения после знака =, без пробелов и кавычек:
        TELEGRAM_TOKEN=ваш токен из BotFather
        AI_API_KEY=ваш ключ нейросети
        ADMIN_IDS=ваш Telegram ID
   3. Если ваш сервис нейросети не тот, что указан в коде по умолчанию, впишите также
      AI_BASE_URL, ID_MODEL, VISION_MODEL, FALLBACK_MODEL и MODELS (подсказки в самом файле).
   4. Положите .env в одну папку с main.py.

СПОСОБ Б. Через «Переменные окружения» в панели хостинга
   В панели хостинга ищите раздел «Переменные», «Variables» или «Environment».
   Добавьте туда те же имена и значения, что в способе А (TELEGRAM_TOKEN, AI_API_KEY, ADMIN_IDS ...).
   Файл .env в этом случае не нужен.

Важно: токен и ключ — как пароли. Никому не показывайте и не выкладывайте в интернет.


ЧАСТЬ 3. ЗАПУСК

ВАРИАНТ 1. Хостинг с панелью (Amvera, Railway, Render, Bothost, Timeweb Apps и подобные)
   1. Создайте новое приложение/проект типа «Python» (или «Бот»).
   2. Загрузите файлы main.py и requirements.txt (и .env, если выбрали способ А).
   3. В настройках запуска укажите:
        • язык/окружение: Python 3.10 или новее
        • файл с зависимостями: requirements.txt
        • команда запуска: python main.py   (или «стартовый файл»: main.py)
      Зависимости хостинг установит сам при сборке, вводить ничего не нужно.
   4. Если выбрали способ Б, добавьте переменные в разделе «Переменные».
   5. Нажмите «Запустить» / «Deploy». Когда в логах появится строка «Бот запущен!» —
      бот работает.
   6. Чтобы база пользователей не пропадала при перезапуске, включите «постоянное
      хранилище» (если хостинг его даёт). Бот сам сохраняет базу в папку /data, если она
      есть, иначе — в файл bot.db рядом с main.py.

ВАРИАНТ 2. Свой сервер (VPS) или компьютер
   Здесь нужен терминал (командная строка). Выполните по очереди:
        pip install -r requirements.txt
        python main.py
   (в Windows вместо python иногда нужно py, в Linux — python3).
   Чтобы бот работал постоянно, а не только пока открыто окно, на сервере его запускают
   как службу (systemd) или через screen/tmux — спросите у хостинга или у меня.

ЧАСТЬ 4. ПРОВЕРКА
   1. Откройте своего бота в Telegram, нажмите «Старт», выберите язык, задайте вопрос.
   2. Админ-панель: отправьте боту команду /admin (работает только для ID из ADMIN_IDS).
      Там: статистика, пользователи, рассылка, бан, смена модели, лимиты, промпты, бэкап базы.
   3. Фото и файлы (txt, код, docx, pdf, xlsx, pptx) бот читает сам, настраивать ничего не нужно.


ЧАСТО ВСТРЕЧАЕТСЯ
   Бот молчит
     Проверьте токен, ключ нейросети и ADMIN_IDS. Посмотрите логи: там написана причина.
   «Ошибка ИИ» или бот не отвечает на вопросы
     Проверьте AI_BASE_URL, ID_MODEL и баланс у сервиса нейросети.
   Изменили настройки, а ничего не поменялось
     Перезапустите приложение.
   Не читает PDF
     Убедитесь, что хостинг установил библиотеки из requirements.txt (пересоберите приложение).
   Сообщение «Админ не настроен»
     Не задан ADMIN_IDS. Отправьте боту /myid, впишите число в ADMIN_IDS и перезапустите.
